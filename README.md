# AI Text Cleaner

A lightweight, ultra-fast Go CLI utility designed to strip unwanted Markdown artifacts, formatting clutter, and AI signatures from text files generated by LLMs.

## Key Features
* **Path-Agnostic Processing:** Process `.txt` files from any location on your system (e.g., your `Downloads` folder) without moving or renaming them.
* **Smart Output Naming:** Automatically generates `clean_<filename>.txt` right alongside the original source file.
* **Single-Pass Performance:** Leverages Go's `strings.NewReplacer` for near-instant execution.
* **Zero External Dependencies:** Built 100% with the Go standard library (`os`, `path/filepath`, `strings`, `fmt`).

## Artifacts Cleaned Automatically
* Code block ticks (```)
* Horizontal dividers (`---`)
* Markdown headers (`###`, `####`, etc.)
* Em-dashes (`—`) converted into clean commas (`, `)

## Quick Start

### 1. Prerequisites
Ensure you have [Go](https://go.dev/dl/) installed on your system.

### 2. Run from Source
Pass the absolute or relative path of any file directly to the script:

powershell

`go run AI-Cleaner.go "C:\Users\<YourUsername>\Downloads\sample.txt"`

### 3. Build as Executable
Compile into a standalone binary:

```go build -o aiclean.exe AI-Cleaner.go```

Then run it directly:

```.\aiclean.exe "C:\Users\<YourUsername>\Downloads\sample.txt"```

You should now see a the same txt file appear in your Download folder with the name clean_textfile.txt.
